三個問題分開判斷

每個來源要分開判斷三件事：是否可靠、內容是否已核實，以及網站是否有權保存或重刊。三者不能互相代替。公開網頁可能受版權保護；開放授權文件仍可能有研究限制；館藏 API 可以開放元資料，圖像卻可能另有條款。

來源入庫前要記錄原始網址、出版者、作者、日期、類型、取得時間、內容雜湊和權利證據。連結失效後，仍保留書目和最後核實日期，但不假裝原文仍然取得到。

權利狀態及網站行為

OPEN_ACCESS 只在授權或機構政策清楚時保存容許的全文；COPYRIGHT_RESTRICTED 只保留書目、短摘和定位；VIEW_ONLY 及 LINK_ONLY 不下載重刊內容；METADATA_ONLY 只使用出版資料。權利不明時採最保守狀態，待證據補足才升級。

Nature 摘要、河南博物院頁和配器網站，在本站只作短摘和原站連結；Luan 的開放預印本則按來源權利保存研究用全文。Met 開放 API 的物件元資料和網站圖片，仍分開處理。

引用必須指向能重現的位置

PDF 用頁碼，網頁用標題、段落和短文字錨點，館藏用欄位，影音用開始及結束時間。文章段末的來源卡只顯示主要資料；逐條主張仍保留自己的定位。若來源只有搜尋結果摘要，必須回到原頁；回不到原頁，便不能升作已核實主張。

短摘只取核對所需的字詞，不連續重現大段內容。正文以自行撰寫的綜合和解釋為主，也要保留來源原有的語氣。

同一作品可能有多重權利

曲目頁可能同時涉及作品、改編、譜面、錄音、表演和封面圖像。某首傳統曲調進入公眾領域，不表示現代整理譜或新錄音可以自由轉載。網站逐件記錄版本和權利持有人，不用曲名作一刀切判斷。

教學頁可以描述技法和提供自製練習，但不重製受保護教材的大量譜例。需要原譜時，只連到合法購買、館藏或出版者頁面。

影音採連結優先及時間碼證據

公開影片只在平台條款容許時嵌入或連結，不下載後重新發布。證據卡記錄標題、頻道、時間段、可聽見或可看見的具體現象，以及核實日期。影片被刪除後，相關主張要降級或另找合法來源。

演奏錄音不會因為用於教學，便自動符合合理使用；公開前仍要確認作品、表演及錄音權。

更正、撤下與權利人聯絡

權利人可以指出具體頁面和材料，要求檢查。編輯會先暫停相關全文或媒體公開，再核對授權、來源和使用範圍；確認不適合重刊時，保留書目並移除內容，記下處理日期。

政策頁本身也有版本號。任何放寬保存或重刊規則的改動，都必須有新的權利證據和人工覆核，不由自動程式猜測。
