笛子百科

從形制與音色入門，逐步讀到演奏、製作、人物和作品。這裏收錄 60 篇已成文專題；未成文的索引另存研究文庫。

初識竹笛演奏與練習樂器、製作與聲學歷史與地域人物與傳承作品研讀研究方法

初識竹笛

8 篇

選購、日常保養與季節管理

把每次吹奏後、定期清潔、環境控制、接頭護理和換膜分成可以實行的保養節點。

L2
笛膜：材料、貼法、聲學與故障

由膜孔位置、振動作用、鬆緊反應和日常檢查入手，說清笛膜已能證實的聲學作用，以及仍待補證的貼法細節。

L2
笛、橫笛、竹笛與相關名稱辨析

用吹奏方向、材料、膜孔、年代和來源語境拆解「笛」「笛子」「橫笛」「篪」「骨笛」等名稱，避免把同名或近名器物誤作同一形制。

L2
竹笛結構：吹孔、膜孔與按音孔

按實際排列說明笛塞、吹孔、膜孔、按音孔、尾孔和可調接頭，並交代各項資料的適用範圍。

L2
調性、筒音與實際音高

把笛身調名、筒音作幾、簡譜的 1 和實際音高拆開處理，避免最常見的調性誤讀。

L2
曲笛、梆笛、新笛與大笛比較

先以有文獻支持的曲笛／梆笛比較建立尺度，再說明新笛和大笛目前能查到、以及尚待補證的部分。

L2
音域、移調與簡譜／五線譜

比較文獻中的實用音域說法，交代記譜音與實音的差別，以及半音和跨筒音寫作的限制。

L2
竹笛是甚麼：形制、聲音與用途

先界定這個知識庫所說的竹笛，再由結構、笛膜、常見類型與演奏用途建立基本概念。

L2

演奏與練習

14 篇

循環換氣：機制、分段練習與音樂用途

說明口腔儲氣與鼻吸的交接，安排由水泡練習到竹笛長音的次序，並區分技巧成功與樂句自然。

L2
竹笛學習地圖：能力關卡、練習設計與評量

由第一次發音到中級曲目整合，以能力關卡、單變項練習、錄音證據和作品專題組成可調整的教學架構。

L2
竹笛技法總覽：由發音、運指到風格語彙

按身體協調、發音、運指、吐奏、裝飾、換氣和音樂語境整理技法次序，提供可診斷的學習路線及跨技法關係圖。

L2
雙吐

由記號、音節、使用脈絡和已核實示範入手，建立循序練習及自我檢查的雙吐基礎。

L2
發音、口風與氣流方向

把風門、口風、氣流速度和音區變化分開處理，建立可觀察、可錄音和可修正的發音方法。

L2
花舌：兩種發聲路徑、音色差異與使用語境

比較舌尖和喉部兩類花舌路徑，說明北方曲目脈絡、練習次序、個體差異和安全停止條件。

L2
半孔與叉指

分辨半孔和叉指的動作、音準代價及使用場景，並提供可以核對的慢速練習框架。

L2
長音：由穩定氣流到音準、音色與耐力

以呼吸支援、起音、穩定段和收音四部分拆解長音，提供可量度、也不鼓勵過度憋氣的練習框架。

L2
打音、疊音與贈音：方向、時值及句法功能

以《姑蘇行》的打音、疊音、贈音和顫指為例，區分由下、由上及句尾點音的方向與功能，並處理中文術語和 grace note 並不完全對等的問題。

L2
單吐：起音、時值與樂句中的清晰度

由音節提示、現代與傳統語境、均勻度和慢速排錯入手，建立單吐的可評量學習頁。

L2
滑音與抹音：連續音高、階梯效果及筒音限制

區分連續與階梯式滑動，說明按孔、口風、筒音邊界、樂句功能和作曲標示的需要。

L2
顫指：速度、均勻度、起始音與風格

把顫指的手指動作、起始音、速度和流派語境分開，提供由單指到樂句的量化練習方法。

L2
三吐：三音分組、重音輪廓與高速均勻度

解釋三吐的記號、音節提示、曲目脈絡，以及由慢速三音組到連續音型的練習次序。

L2
氣震音與顫音：音高、音量及手指控制的分別

釐清氣息和手指兩大控制來源、音高和音量兩種振動維度，以及何時應延後加入顫音。

L2

樂器、製作與聲學

8 篇

大笛：低音域、樂隊角色與當代曲目

以音樂學院講座和學位論文界定大笛的相對音域、音色、樂隊用途及早期代表曲目，同時交代名稱與規格仍有彈性。

L2
笛膜如何改變共振、音準與諧和性

用膜的質量—彈簧模型和實測導納作比較，說明笛膜不只是加上沙聲，也會按指法和共振位置改變峰值頻率、幅度及諧和性。

L2
從管徑、孔位到調音：竹笛幾何與聲學工作流程

把天然竹管量測、內徑與壁厚、孔徑孔高、膜孔、尾孔和多指法調音串成可追溯的製作流程，說明模型、台架量測和真人試吹各自負責甚麼。

L2
竹笛共鳴器聲學：氣柱、輸入導納與共振峰

把竹笛拆成激發、共鳴和輻射三層，說明氣柱、輸入導納、共振峰、音孔晶格和截止頻率怎樣連到音準、可吹奏性與音色。

L2
竹笛與簫、篪、長笛：形制與證據比較

按吹奏方向、材料、吹孔、膜孔、按音孔、尾孔、年代和用途，比較竹笛、簫、古代篪及西洋長笛，避免只憑「flute／笛」一字便視為同種樂器。

L2
八孔笛：戴亞的改良實踐與教學制度

核對八孔笛在 1990 年代舞台實踐及 2008 年教材化的兩個節點，並說明現有來源不足以建立跨製作者的唯一孔位圖。

L2
十孔笛：川音傳承、半音需求與樂隊融合

聚焦四川音樂學院十孔笛系統，整理研製歸屬、1950 年代教學沿革、改良目的及當代傳承條件。

L2
新笛、多孔笛與加鍵笛：改良目標、形制及名稱邊界

以大學博物館、配器研究和博士論文，區分無膜十一孔新笛、帶膜加鍵笛及其他現代改良方案。

L2

歷史與地域

4 篇

從考古吹管樂器到現代竹笛：證據與限度

沿賈湖骨笛、周代篪及清代館藏竹笛，排出分層時間線；逐項交代年代、材料、吹奏方向及證據限度，不把考古上的早期器物直接說成現代竹笛祖先。

L2
竹笛地域與流派：北方、江南及當代交會

以梆笛、曲笛、戲曲和江南絲竹的可核資料畫出地域地圖，同時說明「南北派」是有用的歷史框架，不是固定本質。

L2
北派、南派及當代風格分類

把南北分類放回戲曲、地方合奏、樂器形制和演奏語彙中理解，避免把概括標籤當成固定本質。

L2
20 世紀竹笛獨奏化與專業教育

以 1949 年後的專業演奏者、訓練制度、獨奏曲目和田野研究為線索，說明現有來源能支持的歷史觀點及其限制。

L2

人物與傳承

11 篇

陳中申：笛簫、作曲、指揮與半音笛研發

整合台灣教育機構資料，建立陳中申由演奏、作曲、指揮到陳氏半音笛研發的可追溯年表。

L2
竹笛人物與機構：如何建立可核實的傳承網絡

以馮子存、劉管樂、陸春齡、趙松庭四個個案，說明人物生平、師承、曲目、教學、機構及紀念敘事應怎樣分層核實。

L2
馮子存：由民間伴奏語彙走向竹笛獨奏舞台

以可定位的學術及院校資料，梳理馮子存的地域根源、曲目整理、教學工作和竹笛獨奏專業化角色。

L2
劉管樂：北方梆笛、曲目創編與專業傳承

從生平、梆笛專長、代表曲目和院校傳承四方面，建立劉管樂的可追溯人物檔案。

L2
陸春齡：江南絲竹根基與現代專業笛樂

以高等音樂院校、樂器博物館和學術資料，梳理陸春齡的江南絲竹根基、創編曲目、教學和傳承。

L2
譚寶碩：洞簫演奏、造簫與香港跨媒介實踐

由香港政府及康文署資料整理譚寶碩的嶺南師承、低音與巨型洞簫研製、錄音出版及文學講座。

L2
唐俊喬：當代作品首演、竹笛教育與舞台策劃

以三所音樂院校資料核實唐俊喬的職務、首演與出版數字、竹笛樂團及《愁空山》教學實踐。

L2
俞遜發：口笛創新、舞台實踐與《琅琊神韻》

以博物館、大學及館藏資料整理俞遜發的口笛創新、代表作品和錄音角色，並公開兩種口笛年代說法。

L2
曾永清：北派師承、跨流派學習與《秦川情》

整理曾永清由天津、中央音樂學院少年班到專業舞台的年表，並以兩個來源重建劉管樂與馮子存的師承線。

L2
張維良：演奏、教育、創作與竹笛樂團建設

由師承、作品、院校教學和樂團創建四條線索，整理張維良跨演奏、教育及藝術策劃的工作。

L2
趙松庭：婺劇根源、南北交融與竹笛教學系統

從婺劇成長背景、代表作品、樂器改良和教學制度四條線，理解趙松庭的藝術與教育貢獻。

L2

作品研讀

11 篇

竹笛曲目研究法：來源、曲式、技法與版本比較

以《五梆子》《喜相逢》《鷓鴣飛》《三五七》示範怎樣由曲調來源、改編者、結構、技法、譜本和錄音建立可核查的曲目頁。

L2
《姑蘇行》：江南曲笛語彙、三段結構與版本辨識

由署名、創作年代、崑曲素材、曲式、裝飾音和錄音目錄，建立《姑蘇行》的可核查作品導讀。

L2
《牧民新歌》：蒙古族素材、四段敘事與速度技法

由簡廣易的作品署名、蒙古族音樂素材、四段曲式、馬頭琴意象、吐音技法和版本調性建立導讀。

L2
《帕米爾的春天》：塔吉克族素材、署名差異與研究入口

以出版機構曲目說明和國家教育曲目庫，核對《帕米爾的春天》的署名、素材、性格及當代教學位置。

L2
《三五七》：婺劇唱調、四段結構與趙松庭的獨奏改編

由婺劇唱調和伴奏質地出發，說明趙松庭 1957 年改編的四段結構、循環換氣和當代曲目地位。

L2
《五梆子》：曲牌來源、馮子存改編與三次變奏

分清傳統曲牌、演奏整理和記譜層次，再按可定位資料說明《五梆子》的結構、技法和當代曲目地位。

L2
《喜相逢》：民間曲調、四段變奏與北方梆笛語彙

由民間素材、馮子存改編、四段結構、演奏技法和今日院校曲目地位，介紹《喜相逢》的形成與流傳。

L2
《揚鞭催馬運糧忙》：東北音樂語彙、三段曲式與梆笛動能

由創作年代、東北素材、三段結構、問答句法、吐音和顫音配置，分析《揚鞭催馬運糧忙》。

L2
《蔭中鳥》：河北嗩吶素材、鳥鳴模仿與北派梆笛句法

把《蔭中鳥》的署名、素材、三段結構、固定音型、鳥鳴技法、演奏配置及史料限度逐項拆開。

L2
《早晨》：趙松庭的南北融合、三段布局與循環換氣

用兩個獨立來源分辨《早晨》的年代說法、曲式、節拍、循環換氣、南北技法和演奏配置。

L2
《鷓鴣飛》：湖南傳統樂曲與陸、趙兩個竹笛版本

把曲名背後的早期文獻、陸春齡改編、趙松庭版本和演奏分析分開，避免混淆兩條傳承。

L2

研究方法

4 篇

竹笛錄音、數碼分析與人工智能：研究地圖與資料標準

分開錄音保存、聲學量測、訊號分析、物理建模、聲音合成和人工智能任務，列出建立可重現竹笛數碼資料集的最低欄位。

L2
編輯、同行覆核及更正政策

說明 AI 輔助編輯、內部編輯、外部學科專家和教學專家的權限差異，以及主張衝突、版本更新、撤稿及 L4 驗收程序。

L2
如何閱讀本知識庫的證據及核實狀態

解釋 L0 至 L4、來源等級、逐項主張、定位器、信心、權利狀態及待考標記，讓讀者知道每一頁能證明甚麼，尚不能證明甚麼。

L2
來源、權利與引用政策

列明來源入庫、合法保存、全文重刊、短摘、定位引用、影音連結及撤下程序，讓可核實性和權利要求同時成立。
